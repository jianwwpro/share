"频率/反复"表达 系统对比

语法 读音 核心含义 关键区别
度に たびに 每次做某事时都… 强调同一感受反复出现 ✅
ごとに ごとに 每隔… 强调固定间隔/周期 ✅
続く つづく 持续/接连不断 强调状态不中断 ✅
〜といつも 〜というときはいつも 一…就总是… 强调条件反射式的习惯 ✅
〜時はいつも 〜ときはいつも …的时候总是… 强调特定场景下的固定反应 ✅
ずつ​ 每…各… 平均分配
语法 读音 核心含义 关键词 数字？
ぶり ぶり 时隔…（之久） 久违/隔了多久 ✅ 必须有时间量
〜につき 〜につき 每… 按比例/按单位 ✅ 必须有数量
ずつ つづ 每…各… 平均分配 ✅ 必须有数量
ごとに ごとに 每隔… 固定间隔、有累加语感 ✅ 必须有数量
度に たびに 每次…都… 感受反复 ❌ 无数字

有数字/数量？

  ├─ YES → 是分配吗？
  │         ├─ YES → ずつ（一人ずつ）
  │         └─ NO  → ごとに（10分ごとに）
  └─ NO  → 是感受反复？
            ├─ YES → 度に（使う度に）
            └─ NO  → 是持续状态？
                      ├─ YES → 続く（雨が続く）
                      └─ NO  → 是条件反射？
                                ├─ YES → 〜といつも
                                └─ NO  → 〜時はいつも
