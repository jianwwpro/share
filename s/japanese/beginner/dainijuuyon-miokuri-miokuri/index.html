第二十四课 見送り　みおくり

所思所言，ん口语，が引话题

  1. 李さんは　もう　すぐ　来ると　思います。

AN/N だ　と　思います。

馬さんは　日本へ　行きたい　と　思っています。小马想去日本 -反复

馬さんは　日本へ　行きたい　と　思いました。 小马过去想去日本 -过去

馬さんは　日本へ　行きたい　と　思っていました。　过去一段时间想去日本 -过去反复

私は　日本へ行きたい　と　思います。

私は　日本へ行きたい　と　思っています。

私は　日本へ行きたい　と　思いました。

私は　日本へ行きたい　と　思っていました。

  1. 陳さん（ちん）は　パーティーに　行くと　言いました。

に：行动的目的

と：提示说的内容

Nは　小句（简体形）　と　言いました。

小野さんは　李さんに　ちょっと　休みたい　と　言いました。

来週の　ハイキング　張さんも　行きたい　と　言って　います。

  1. すみません、頭が　痛いんです。

~んです：解释说明，口语

〜のです：书面语

～の：形式名词

タバコは　やめた　方が　いいですよ。

ーーそうなんですが、やめる　ことが　できないんです。

すごい人気ですね。

ーーええ、あの歌手は　日本は　日本では　とても　有名なんです。

  1. 東京タワーへ　行きたいんですが、どうやって行きますか。

どうやって：どう＋やる 如何做

どうやって：如何做？

どうする：怎么办？

どうした：怎么了？

どうして：为什么？

A：日本の　音楽に　ついて　どう　思いますか。

B：素晴らしいと　思います。

～について（关于什么）

A：課長は何と言いましたか。

B：午後から出かけると言いました。

出かける　＝　家を出る

外へ出かける　＝　外出（がいしゅつ）する
